# Asifa B's Personal Portfolio Website

Welcome to the repository for my personal portfolio website! This is a modern, single-page web application designed to showcase who I am, the projects I've built, and my professional certificates. It features a sleek dark UI, glassmorphism aesthetics, scroll reveal animations, and interactive project modals.

### 🌐 Live Preview:
*(You can host your `index.html` on GitHub Pages or Vercel and put the link here)*

## 🚀 Features
- **Responsive Design**: Flawless display across all devices (Mobile, Tablet, Desktop).
- **Dark Mode UI**: A premium dark aesthetic using dynamic CSS variables.
- **Micro-Interactions**: Hover effects on cards, buttons, and social links for a reactive feel.
- **Scroll Reveal Animations**: Sections fade and slide into view seamlessly as you scroll down the page.
- **Interactive Modals**: Detailed project modals providing deeper insights and live demo (`Play Game`) links alongside GitHub repository links.
- **Google Drive Integration**: Direct navigation to an organized folder holding my professional credentials and certificates.

## 🛠️ Tech Stack
This portfolio is built lightweight and fast.
- **HTML5**: Semantic and accessible document structure.
- **CSS3** (Vanilla): CSS Grid & Flexbox layouts, Custom Properties (Variables), Animations, and `backdrop-filter` for glass UIs.
- **JavaScript** (Vanilla ES6): DOM manipulation for navigation toggling, smooth scrolling, and Interaction Observer API based reveals.
- **Phosphor Icons**: A flexible icon family for modern interfaces.
- **Fonts**: 'Inter' and 'Outfit' typography via Google Fonts.

## 📂 Project Highlights Included
1. **Neurogrid Memory Game**: A web-based collection of cognitive training games.
2. **Epileptic Seizure Detection System**: A Machine Learning-based web app detecting seizures via EEG.
3. **Online Scrap Portal**: A web-based platform streamlining scrap collection.

## 💻 Local Setup & Development
Since this is a vanilla HTML/CSS/JS project, there is no package manager or build step required!

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AsifaB-06/portfolio.git
   ```
2. **Navigate into the directory:**
   ```bash
   cd portfolio
   ```
3. **Run the site:**
   Simply double-click the `index.html` file to open it in your default web browser, or use an extension like VSCode's **Live Server** to spawn a local development server.
